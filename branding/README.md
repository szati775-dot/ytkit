# Channel branding

Banner and profile picture for the Grinder channel, rendered from the Blender Shorts characters.

- `brand_render.py` runs an episode script up to its RENDER section, jumps to a time and renders one still (optionally a transparent cut-out of one character).
- `tweak_*.py` place the characters and the camera for each banner.
- `compose.py` adds the text and builds the banner, profile picture and preview sheets.
- `banner-helicopter.jpg` (2560x1440, text inside the 1546x423 safe area) and `profile-helicopter.jpg` (800x800) are the set in use since 15 Nov 2026.
