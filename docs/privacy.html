ytkit privacy policy

Last updated 9 November 2026.

ytkit is a personal tool used only by the owner of the YouTube channel Grinder (@grinder5) to manage that channel.

What data it uses

When the channel owner signs in with Google, ytkit uses the YouTube Data API, YouTube Analytics API and YouTube Reporting API to read the channel's videos, statistics, analytics reports and comments, to upload videos, to edit video details and thumbnails, and to reply to comments, only when the owner asks it to.

Where it is kept

The sign-in token is stored only on the owner's own computer and in the owner's private settings. ytkit has no server of its own and does not send data to anyone other than Google. It does not sell, share or use any data for advertising.

Other people's data

Public comments and public video statistics from YouTube are read only to manage the channel and are not stored beyond what the owner needs for that work.

YouTube and Google

ytkit uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: contact the channel owner through the Grinder YouTube channel.
